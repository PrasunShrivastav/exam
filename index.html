1.1 Machine Learning basics, algorithm selection and applications May 2023; May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

1.1.1 What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence that enables a computer system to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Basic idea: learn from known examples, then apply the model to new examples.

1.1.2 Business applications of ML (learn any five)

  1. Recommendation systems: Online stores and streaming platforms study user history and recommend products, movies or music.
  2. Fraud detection: Banks identify unusual card or UPI transactions using patterns in transaction amount, location, time and user behaviour.
  3. Customer segmentation: Clustering groups customers by purchasing habits so businesses can design targeted marketing campaigns.
  4. Sales and demand forecasting: Past sales, season, price and trends are used to estimate future demand and manage inventory.
  5. Predictive maintenance: Sensor readings from machines are analysed to predict failures before they occur, reducing downtime.
  6. Chatbots and sentiment analysis: NLP models understand customer messages, answer common questions and identify positive/negative feedback.
  7. Healthcare: Models assist in analysing scans, predicting risk and supporting clinical decisions.
Memory cue: Recommend - Fraud - Segment - Forecast - Maintain. Any five with a clear explanation are enough.

1.1.3 How to choose the right ML algorithm?

There is no single best algorithm for every problem. Select an algorithm based on:

  1. Problem type: Predict a number (regression), predict a class (classification), discover groups (clustering), or reduce features (dimensionality reduction).
  2. Availability of labels: Labelled data suggests supervised learning; unlabelled data suggests unsupervised learning.
  3. Dataset size and quality: Small datasets may suit simpler models; large datasets can support more complex models. Missing values and noise must be handled.
  4. Relationship in data: Linear models suit approximately linear relationships; trees and kernel methods can capture non-linear patterns.
  5. Accuracy and interpretability: In regulated decisions, an interpretable model may be preferred over a complex black-box model.
  6. Training time and resources: Consider memory, computation, inference speed and deployment hardware.
  7. Validation performance: Compare candidates using a validation set or cross-validation and suitable evaluation metrics.

Examples: Linear Regression for continuous values; Logistic Regression for binary classes; K-means for grouping; Random Forest for robust classification/regression; PCA for reducing dimensions.

1.1.4 Steps to design a Machine Learning application

  1. Define the problem: Clearly identify the objective, target variable and success measure.
  2. Collect data: Obtain relevant, representative and legally usable data.
  3. Prepare data: Remove duplicates, handle missing values/outliers, encode categories and scale features when required.
  4. Explore and select features: Understand distributions and relationships; select useful input variables.
  5. Split data: Create training, validation and test sets to measure performance on unseen data.
  6. Select and train model: Choose a suitable algorithm and fit it using training data.
  7. Tune and evaluate: Adjust hyperparameters using validation/cross-validation; report suitable metrics on test data.
  8. Deploy and monitor: Integrate the model into the application and monitor accuracy, data drift and fairness. Retrain when needed.
Memory sequence: Problem - Data - Clean - Features - Split - Train - Evaluate - Deploy/Monitor.

1.1.5 Issues in Machine Learning

  • Insufficient or unrepresentative data: The model cannot learn all real-world cases.
  • Poor data quality: Missing values, wrong labels, duplicates, noise and outliers reduce performance.
  • Irrelevant features / high dimensionality: Too many or useless inputs increase complexity and may cause overfitting.
  • Overfitting: Model memorises training data and performs poorly on new data.
  • Underfitting: Model is too simple to capture the actual pattern.
  • Bias and variance: High bias causes systematic errors; high variance causes sensitivity to training samples.
  • Class imbalance: A model may favour the majority class and have poor recall for minority cases.
  • Data leakage: Information from test/future data accidentally enters training, giving misleadingly high scores.
  • Compute and deployment: Large models can require high memory, time and power.
  • Ethics and maintenance: Bias, privacy, explainability and changes in real-world data (concept drift) must be managed.

1.1.7 Training error, generalization error, overfitting, underfitting and bias-variance trade-off

Training error is the error measured on data used to fit the model. Generalization error is the error on new, unseen data; test-set error is an estimate of it.

Conceptual curves: training error usually falls as complexity grows; generalization error often falls then rises.
  • Underfitting: Model too simple; high training and test error; associated with high bias.
  • Good fit: Learns important patterns and performs similarly on training and unseen data.
  • Overfitting: Learns noise/details in training data; very low training error but high test error; associated with high variance.
  • Bias-variance trade-off: Increasing complexity can reduce bias but increase variance. Choose complexity giving low validation/test error.
Expected test error = Bias² + Variance + Irreducible noise

Bias is the systematic error from overly simple assumptions; variance is the error from being sensitive to the particular training sample; irreducible noise is randomness in the data that no model can remove. A good model keeps bias and variance low at the same time.

Ways to control: use more representative data, cross-validation, regularization, feature selection, pruning, early stopping, dropout (for neural networks), or reduce model complexity.

1.1.8 Bias-variance trade-off - easy example

Suppose we predict exam marks from study hours. A very simple straight-line model may miss a curved relationship (high bias / underfitting). A very complex curve may pass through every training point, including random noise (high variance / overfitting). A model of suitable complexity captures the real trend and performs well on new students.

2.1 Regression, scatter plot, best-fit line and numericals May 2023; May 2024; May 2025; Nov 2025; Jun 2026

2.1.1 Regression line, scatter plot, prediction error and best-fitting line

Regression predicts a continuous numerical output from one or more input variables. In simple linear regression, one input x is used to predict y.

ŷ = a + bx    where a = intercept and b = slope
  • Scatter plot: Graph with input x on the horizontal axis and observed output y on the vertical axis. Each data pair is shown as a point.
  • Regression line: A straight line that summarises the relationship between x and y.
  • Prediction: For a value x, the predicted output is ŷ = a + bx.
  • Prediction error / residual: Difference between actual and predicted value: e = y - ŷ. A positive residual means the actual value is above the line.
  • Best-fitting line: The line chosen to minimise the sum of squared residuals (least squares).
A best-fit line follows the overall trend; the vertical distance from a point to the line is its residual.

2.1.2 Least-squares formulas

b = [nΣxy - (Σx)(Σy)] / [nΣx² - (Σx)²]
a = [Σy - bΣx] / n    therefore   ŷ = a + bx

2.1.6 Multivariate Linear Regression

Multivariate (multiple) linear regression predicts one continuous dependent variable using two or more independent variables.

y = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε
  1. Identify the target y and input features x₁, x₂, ... xₚ.
  2. Collect and clean data; encode categorical variables and scale where useful.
  3. Estimate coefficients β using least squares, minimising the sum of squared residuals.
  4. Interpret each coefficient as the expected change in y for a one-unit change in that feature, keeping other features fixed.
  5. Evaluate on unseen data using MAE, MSE, RMSE and R².

Example: House price may be predicted from area, number of bedrooms, age and location score. It is useful when several factors jointly influence a numerical outcome.

2.1.7 Linear Regression - short note

Linear regression models the relationship between an independent variable and a continuous dependent variable using a straight line. It estimates parameters by least squares, then uses the fitted equation for prediction. Advantages: simple, fast and interpretable. Limitations: sensitive to outliers, assumes a linear relationship and may perform poorly when important non-linear patterns are present.

2.2 Logistic Regression May 2023; Nov 2024; May 2025; Nov 2025; Jun 2026

Logistic Regression is a supervised classification algorithm. Although its name contains “regression”, it predicts the probability of a class, commonly Yes/No or 0/1.

2.2.1 Sigmoid function

First calculate a linear score z, then convert it to a probability using the sigmoid (logistic) function:

z = β₀ + β₁x₁ + ... + βₚxₚ
P(y=1|x) = 1 / (1 + e⁻ᶻ)

The output lies between 0 and 1. A threshold (commonly 0.5) converts the probability into a class: probability ≥ threshold → class 1; otherwise class 0.

The sigmoid maps any real-valued score to a probability between 0 and 1.

2.2.2 Working steps

  1. Collect labelled data and prepare/encode features.
  2. Calculate a linear combination of input features.
  3. Apply the sigmoid function to obtain the probability of the positive class.
  4. Learn coefficients by minimising log-loss (cross-entropy), commonly using an optimisation method such as gradient descent.
  5. Choose a classification threshold and predict the class.
  6. Evaluate using confusion matrix, accuracy, precision, recall, F1 and ROC-AUC as suitable.

2.2.3 Advantages and limitations

Advantages: simple, fast, interpretable coefficients, gives class probabilities and works well when the log-odds are approximately linear in features. Limitations: a linear decision boundary unless features are engineered; may underfit complex relationships; affected by multicollinearity and requires suitable feature preparation.

Applications: spam/not-spam, churn/no churn, disease/no disease, loan default prediction and click-through prediction.

2.3 Entropy, Gini Index and decision-tree numericals May 2023; May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

2.3.1 Entropy and Gini Index

Both measure impurity (mixing of classes) in a dataset or decision-tree node. A pure node has impurity 0. A node with a balanced mixture has higher impurity.

Gini(D) = 1 - Σ pᵢ²
Entropy(D) = -Σ pᵢ log₂(pᵢ)

Here pᵢ is the proportion of records belonging to class i. For a split into child groups:

Weighted Gini after split = Σ (|Dⱼ|/|D|) × Gini(Dⱼ)
Gini decrease = Gini(parent) - weighted Gini(children)
Information Gain = Entropy(parent) - Σ (|Dⱼ|/|D|) × Entropy(Dⱼ)

Choose the feature with the lowest weighted Gini (equivalently, greatest Gini decrease). Entropy-based trees commonly choose the split with greatest information gain.

Gini Entropy
Uses squared class probabilities. Uses logarithm of class probabilities.
Computationally simpler. More computationally expensive due to logarithms.
Lower is purer; 0 for a pure node. Lower is purer; 0 for a pure node.

2.3.5 How to handle overfitting in decision trees?

  • Pre-pruning: stop early using maximum depth, minimum samples per split/leaf or minimum impurity decrease.
  • Post-pruning: grow the tree, then remove branches that add little predictive value.
  • Cross-validation: choose depth and pruning settings using validation folds.
  • Limit features: remove irrelevant/noisy features and avoid unnecessary splits.
  • More representative data: reduces the risk of learning accidental patterns.
Numerical method to memorize: (1) Count classes at parent. (2) Find parent Gini. (3) For each feature, count classes in each branch. (4) Find each branch Gini. (5) Weighted sum. (6) Pick minimum and draw the tree.

2.3.6 CART - Classification and Regression Trees

CART is a decision-tree method used for both classification and regression. It repeatedly divides the data into two smaller groups using binary splits, then predicts from the leaf reached by a new record.

  1. Start with the full training dataset at the root.
  2. Try candidate binary splits on available features.
  3. For classification, select a split that reduces impurity, commonly using Gini index.
  4. For regression, select a split that reduces variance or squared error (MSE).
  5. Split the data into left and right child nodes and repeat recursively.
  6. Stop at a limit (maximum depth, minimum samples, or no useful improvement).
  7. Prune unnecessary branches to reduce overfitting; the terminal nodes are leaves.

Prediction: A classification leaf returns the majority class; a regression leaf returns the mean target value of the training records in that leaf.

Exam note: Gini is a classification impurity measure. For regression trees, CART normally uses variance/MSE reduction. CART supports both tasks, but the split criterion changes.

Advantages: easy to understand, handles numerical and categorical inputs, needs little feature scaling. Limitations: a deep tree can overfit and small data changes can produce a different tree; pruning and ensemble methods help.

2.4 Classification metrics and binary classification numerical May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

2.4.1 Confusion matrix

A confusion matrix compares actual classes with predicted classes.

Predicted Positive Predicted Negative
Actual Positive TP - correctly predicted positive FN - positive predicted as negative
Actual Negative FP - negative predicted as positive TN - correctly predicted negative

2.4.2 Important metrics and formulas

  • Accuracy: Overall fraction of correct predictions.
  • Precision: Out of all predicted positives, how many are actually positive.
  • Recall / Sensitivity: Out of all actual positives, how many were correctly found.
  • Specificity: Out of all actual negatives, how many were correctly identified.
  • F1-score: Harmonic mean of precision and recall.
Accuracy = (TP + TN)/(TP + TN + FP + FN)
Precision = TP/(TP + FP)   |   Recall = TP/(TP + FN)
Specificity = TN/(TN + FP)   |   F1 = 2 × Precision × Recall/(Precision + Recall)

2.4.4 Which metric should be used?

Accuracy is useful when classes are reasonably balanced and error costs are similar. Precision matters when false positives are costly (for example, incorrectly flagging a legitimate email as spam). 2.4.5 Additional classification measures: Kappa and ROC curve

Cohen's Kappa (κ) measures agreement between predicted and actual classes after correcting for agreement expected by chance.

κ = (Pₒ - Pₑ) / (1 - Pₑ)

Pₒ is the observed agreement (normally accuracy); Pₑ is the expected chance agreement calculated from the row and column totals. κ = 1 means perfect agreement, κ = 0 means chance-level agreement, and a negative value means worse than chance agreement.

A curve closer to the top-left is better. AUC summarises the curve; 1 is perfect separation and about 0.5 is random ranking.

3.1 Ensemble learning: Bagging, Boosting, Random Forest and XGBoost May 2023; May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

3.1.1 Ensemble learning

Ensemble learning combines predictions from multiple models (called base learners) to produce a stronger and more reliable final prediction than an individual model in many cases.

3.1.2 Bagging vs Boosting

Bagging Boosting
Trains multiple models independently, often in parallel. Trains models sequentially; each new model focuses on previous errors.
Uses bootstrap samples (random samples with replacement). Reweights examples or fits residuals/gradients from earlier models.
Combines by majority vote (classification) or averaging (regression). Combines weak learners using weighted contributions.
Mainly reduces variance and improves stability. Can reduce bias and improve predictive accuracy.
Example: Random Forest. Examples: AdaBoost, Gradient Boosting, XGBoost.
Usually less sensitive to noisy labels than aggressive boosting. Can overfit noisy data if not regularized/tuned carefully.

3.1.3 Random Forest algorithm - detailed answer

Random Forest is an ensemble learning algorithm that builds many decision trees and combines their outputs. It uses bagging and random feature selection to make trees diverse.

3.1.4 Algorithm steps

  1. Take a bootstrap sample from the original training dataset (sample with replacement).
  2. Grow a decision tree on that sample.
  3. At each node, randomly select a subset of input features rather than checking every feature.
  4. Choose the best split among the selected features using a measure such as Gini index (classification) or variance reduction (regression).
  5. Repeat the process to build many trees using different bootstrap samples and feature subsets.
  6. For classification, use majority voting across trees. For regression, take the average of tree predictions.

3.1.5 Advantages

  • Usually gives good accuracy and reduces overfitting compared with one deep decision tree.
  • Works for classification and regression.
  • Handles many features and captures non-linear relationships.
  • Less sensitive to individual training examples.
  • Can estimate feature importance and out-of-bag (OOB) performance.

3.1.6 Limitations

  • More memory and computation than one decision tree.
  • Less interpretable than a single tree.
  • May be inefficient for very large numbers of trees or latency-sensitive systems.

3.1.7 Real-world use cases

Fraud detection, credit-risk assessment, customer churn prediction, medical classification, product demand prediction and equipment-failure prediction.

Memory cue: Random samples + random features + many trees + vote/average = Random Forest.

3.1.8 XGBoost (Extreme Gradient Boosting)

XGBoost is an efficient and regularized implementation of gradient-boosted decision trees. It builds trees sequentially, with each new tree improving the errors/residuals of the current ensemble.

3.1.9 Working steps

  1. Start with an initial prediction (for example, the mean for regression).
  2. Calculate the loss/gradient information showing where predictions are wrong.
  3. Train a new decision tree to improve those errors.
  4. Add the new tree's prediction to the current model using a learning rate.
  5. Repeat for the specified number of boosting rounds.
  6. Use regularization and validation/early stopping to control overfitting.

Important features: L1/L2 regularization, learning-rate shrinkage, row/column subsampling, tree pruning, handling of missing values, and efficient parallel computation for split finding.

Advantages: strong performance on structured/tabular data, flexible objective functions, regularization and efficient implementation. Limitations: requires parameter tuning, can overfit if poorly configured and is less interpretable than a simple model.

Applications: credit scoring, fraud detection, ranking, churn prediction, sales forecasting and structured-data competitions.

Distinguish: Random Forest = many trees built independently then combined. XGBoost = trees built one after another, each correcting earlier mistakes.

3.1.10 Different ways to combine classifiers

After several classifiers make predictions, their outputs can be combined to make one final decision.

  1. Majority voting (hard voting): each model votes for one class; the class with the most votes wins.
  2. Soft voting: average the predicted class probabilities and choose the class with the highest average probability.
  3. Weighted voting: give stronger/reliable classifiers more votes or a higher weight.
  4. Probability combination: combine class probabilities using sum/average, product, maximum or minimum rules, depending on the design.
  5. Stacking: train a meta-classifier on the predictions of base classifiers; use out-of-fold predictions to avoid data leakage.
  6. Blending: similar to stacking, but the meta-model is trained using predictions on a held-out validation set.
  7. Regression ensembles: combine numerical predictions using mean or weighted mean.

3.1.11 Subagging and decision stumps

  • Subagging (subsample aggregating): train the same base learner on several random subsets sampled without replacement, then vote/average the predictions. Like bagging, it stabilises predictions, but bagging normally samples with replacement.
  • Decision stump: a very small decision tree with only one split (one internal decision node). It is a weak learner often used in boosting; many stumps are combined to form a stronger model.

3.2 K-fold cross-validation

K-fold cross-validation estimates how well a model will generalize by repeatedly training and validating on different parts of the available data.

  1. Shuffle the dataset when appropriate and divide it into K roughly equal folds.
  2. For each of K rounds, use one fold for validation and the remaining K-1 folds for training.
  3. Record the chosen performance metric for every round.
  4. Calculate the average (and optionally variation) of the K scores.
  5. Choose the model/hyperparameters with good average validation performance, then train the final model on the full training data.

Advantages: uses data efficiently; less dependent on one train-test split; useful for comparing models. Limitations: more computationally expensive. For classification, stratified K-fold preserves class proportions. Keep a final test set untouched until final evaluation to avoid leakage.

  • An ensemble combines several base learners to give a stronger, more stable prediction.
  • Bagging: parallel bootstrap samples, reduces variance → Random Forest. Boosting: sequential, focuses on earlier errors, reduces bias → AdaBoost, XGBoost.
  • Random Forest = bootstrap samples + random feature subsets + many trees + vote/average; OOB error and feature importance come free.
  • XGBoost = regularized gradient boosting; learning rate, L1/L2, subsampling and early stopping control overfitting.
  • Combining classifiers: hard/soft/weighted voting, stacking (out-of-fold), blending, or mean/weighted mean for regression.
  • K-fold: rotate the validation fold K times, average the scores, and keep a final test set untouched until the end.

4.1 Support Vector Machine (SVM), hyperplane, margins and kernel trick May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

4.1.1 What is SVM?

Support Vector Machine is a supervised learning algorithm used mainly for classification (and also regression). It finds a decision boundary, called a hyperplane, that separates classes with the maximum possible margin.

The closest training points to the separating boundary are support vectors; they determine the margin.

4.1.2 Important terms

  • Hyperplane: Decision boundary separating classes. In 2D it is a line; in 3D it is a plane; in higher dimensions it is a hyperplane.
  • Support vectors: Training points closest to the hyperplane. These points determine the optimal boundary and margin.
  • Margin: Distance between the hyperplane and the nearest points of the classes.
  • Optimal separating hyperplane: Hyperplane that maximises the margin, generally improving the ability to generalise.
  • Hard margin: Allows no classification errors; requires linearly separable data and is sensitive to noise/outliers.
  • Soft margin: Allows some violations using slack variables; works better with noisy or overlapping data.
  • Kernel: Function that allows SVM to model non-linear boundaries by computing similarities as if data were mapped to a higher-dimensional space.

4.1.3 SVM optimisation problem

For linearly separable data with labels yᵢ ∈ {-1,+1}, SVM chooses w and b by minimising:

Minimise: ½ ||w||²
Subject to: yᵢ(wᵀxᵢ + b) ≥ 1 for every training example i
Why this maximises the margin: the two boundary planes are wᵀx + b = +1 and wᵀx + b = -1, so the margin width is margin = 2 / ||w|| Minimising ||w||² therefore widens the gap between the classes.

For soft margin, introduce slack variables ξᵢ and penalty C:

Minimise: ½ ||w||² + CΣξᵢ    subject to   yᵢ(wᵀxᵢ+b) ≥ 1-ξᵢ, ξᵢ ≥ 0

C controls the penalty for margin violations: higher C penalises errors more strongly; lower C permits a wider margin with more violations.

4.1.4 Kernel trick and common kernels

The kernel trick calculates inner products in a transformed feature space without explicitly computing the transformation. It enables a linear separator in the transformed space to represent a non-linear boundary in the original space.

Kernel Formula / use
Linear K(x,z) = xᵀz. Suitable when data is approximately linearly separable.
Polynomial K(x,z) = (xᵀz + c)ᵈ. Models polynomial relationships.
RBF / Gaussian K(x,z) = exp(-γ||x-z||²). Handles flexible non-linear boundaries; common general-purpose choice.
Sigmoid K(x,z) = tanh(αxᵀz + c). Similar form to a neural-network activation.

4.1.5 Significance of optimal separating hyperplane

  • Separates the classes using a decision boundary.
  • Maximum margin generally improves generalization on unseen data.
  • Only support vectors determine the final boundary.
  • Can handle high-dimensional feature spaces.
  • Kernel functions allow non-linear classification.

Limitations: choosing kernel and parameters can be difficult; training can be slow on very large datasets; results may be less interpretable; feature scaling is usually important.

Memory cue: SVM = widest safe road between classes. Support vectors are the closest points; kernel bends the boundary by changing the feature space.

4.1.6 Support Vector Regression (SVR)

SVR applies the SVM idea to regression. Instead of separating classes, it finds a function that keeps prediction errors within an acceptable ε-wide tube around the regression function. Errors outside the tube are penalised.

ε-insensitive loss: Lε(y, f(x)) = 0 when |y-f(x)| ≤ ε; otherwise |y-f(x)| - ε

SVR can use linear or non-linear kernels (such as RBF). It is useful for regression with complex patterns, but kernel and parameters such as C and ε need tuning.

4.1.7 Why SVM is a Quadratic Programming (QP) problem

The hard-margin SVM minimises the quadratic objective ½||w||² while satisfying linear constraints yᵢ(wᵀxᵢ+b) ≥ 1. A quadratic objective with linear constraints is a quadratic programming optimisation problem. Soft-margin SVM adds non-negative slack variables ξᵢ and a penalty CΣξᵢ.

The dual formulation is also a quadratic optimisation problem in Lagrange multipliers αᵢ, with constraints 0 ≤ αᵢ ≤ C and Σαᵢyᵢ = 0. Only points with non-zero αᵢ become support vectors.

4.1.8 Soft-margin SVM dual problem (for a fuller 10-mark answer)

Maximise: Σᵢ αᵢ - ½ΣᵢΣⱼ αᵢαⱼyᵢyⱼ(xᵢᵀxⱼ)
Subject to: 0 ≤ αᵢ ≤ C and Σᵢ αᵢyᵢ = 0

For a kernel SVM, replace xᵢᵀxⱼ with K(xᵢ,xⱼ). The predicted class is sign(Σᵢ αᵢyᵢK(xᵢ,x)+b). Support vectors are the training points with non-zero αᵢ.

4.2 Multiclass classification

Multiclass classification assigns an input to one of more than two mutually exclusive classes, such as classifying an image as cat, dog or bird.

Common approaches:

  1. One-vs-Rest (OvR): Train one binary classifier per class. Each classifier separates its class from all remaining classes. Choose the class with the highest score.
  2. One-vs-One (OvO): Train a classifier for every pair of classes. For K classes, the number of classifiers is K(K-1)/2. Use majority voting.
  3. Softmax / native multiclass model: A model produces a score for each class and softmax converts scores to probabilities that sum to 1. Choose the highest probability.

Applications: handwritten digit recognition (0-9), animal/image recognition, news topic classification and disease-type classification.

4.3 Email spam detection - suitable ML technique

Email spam detection is a supervised binary classification problem because training emails are labelled Spam or Not Spam (Ham). A suitable simple technique is Multinomial Naive Bayes , which works well with word-count or TF-IDF features.

  1. Collect a dataset of emails labelled Spam/Ham.
  2. Preprocess text: lowercase, tokenize, remove unnecessary symbols/stop words where appropriate, and convert text to numeric features using Bag-of-Words or TF-IDF.
  3. Split into training and test data.
  4. Train Naive Bayes to estimate prior class probabilities and word likelihoods for Spam and Ham.
  5. For a new email, calculate the posterior probability of each class and predict the class with the larger probability.
  6. Evaluate using precision, recall, F1 and confusion matrix. Precision matters because false spam flags can hide genuine emails; recall matters because missed spam reaches the inbox.

Naive Bayes is fast, efficient for high-dimensional text and works with relatively small datasets. SVM or Logistic Regression can also be used as alternative supervised text classifiers.

  • Hard margin allows no violations; soft margin adds slack ξᵢ and penalty C — larger C means fewer violations are tolerated.

5.1 Clustering: distance metrics, K-means, DBSCAN and MST May 2023; May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

5.1.1 Distance metrics used in clustering

Distance metrics measure how similar or dissimilar two data points are. The metric should match the type and scale of data.

Metric Formula / meaning Common use
Euclidean √Σ(xᵢ-yᵢ)² - straight-line distance. Continuous numerical features.
Manhattan Σ|xᵢ-yᵢ| - sum of absolute coordinate differences. Grid-like movement; sometimes less sensitive to large coordinate differences.
Minkowski (Σ|xᵢ-yᵢ|ᵖ)^(1/p) - general family; p=1 Manhattan, p=2 Euclidean. Flexible numerical distance.
Hamming Number of positions where values differ. Binary or categorical strings/vectors.
Cosine distance 1 - (x·y)/(||x|| ||y||); compares direction/angle. Text vectors and high-dimensional sparse data.

Important: Scale numerical features before distance-based clustering when ranges differ greatly; otherwise a large-scale feature may dominate the distance.

5.1.2 K-means algorithm

K-means is an unsupervised clustering algorithm that divides n data points into K clusters. Each cluster is represented by its centroid (mean point).

  1. Choose the number of clusters K.
  2. Initialize K centroids (often randomly).
  3. Calculate the distance from each point to each centroid.
  4. Assign each point to its nearest centroid.
  5. Recalculate each centroid as the mean of points in that cluster.
  6. Repeat assignment and centroid update until assignments/centroids stop changing or a limit is reached.

Objective: minimise within-cluster sum of squared distances from points to their assigned centroid.

Within-cluster SSE = Σⱼ Σ(x∈Cⱼ) ||x - μⱼ||²    (μⱼ = centroid of cluster j)

Advantages: simple, fast and easy to implement. Limitations: K must be chosen in advance; sensitive to initialization and outliers; works best for roughly spherical, similarly sized clusters; numeric data and suitable scaling are needed.

5.1.3 DBSCAN - Density-Based Spatial Clustering of Applications with Noise

DBSCAN is a density-based unsupervised algorithm. It groups points that are closely packed and marks points in sparse regions as noise/outliers. It does not require the number of clusters in advance.

Two parameters: ε (Epsilon) = neighbourhood radius; MinPts = minimum number of points required in an ε-neighbourhood to form a dense region.

Core point
Has at least MinPts points in its ε-neighbourhood (usually counting itself).
Border point
Has fewer than MinPts neighbours but lies within the ε-neighbourhood of a core point.
Noise point
Is neither a core point nor density-reachable from a core point.
Conceptual illustration of a dense cluster, a border point and an isolated noise point.

5.1.4 DBSCAN steps

  1. Choose ε and MinPts.
  2. Select an unvisited point and find all points in its ε-neighbourhood.
  3. If neighbours are fewer than MinPts, temporarily mark it as noise. If it is later reached from a core point, it can be reclassified as a border point.
  4. If it has at least MinPts neighbours, it is a core point; create a new cluster.
  5. Expand the cluster by adding its density-reachable neighbours. If a neighbour is also core, add its neighbours too.
  6. Continue until all points are visited; remaining unassigned points are noise.

Example: Suppose points A, B, C and D form a dense group where each core point has at least MinPts neighbours within ε. DBSCAN expands one cluster through these connected core points. A nearby point E with too few neighbours but lying inside the ε-neighbourhood of a core point becomes a border point. A far-away point F that is not density-reachable from any core point is labelled noise.

Advantages: finds irregular-shaped clusters, identifies noise, does not need K. Limitations: choosing ε/MinPts can be difficult; struggles when clusters have very different densities; distance becomes less meaningful in very high dimensions.

Memory cue: Epsilon makes the neighbourhood; MinPts decides core; core points grow a cluster; border points join; noise stays outside.

5.1.5 Clustering using Minimum Spanning Tree (MST)

An MST is a tree connecting all vertices of a weighted graph with no cycle and minimum possible total edge weight. For clustering, treat each data point as a vertex and the distance between points as edge weights.

Remove the long bridge edge to separate two natural groups.

5.1.6 Steps

  1. Represent every data point as a vertex.
  2. Calculate pairwise distances and create a weighted graph.
  3. Construct an MST using Prim's or Kruskal's algorithm. The MST contains n-1 edges.
  4. Sort MST edges by weight and remove the largest k-1 edges to obtain k clusters.
  5. Each connected component after cutting is a cluster.

Example: Suppose points A, B, C are close to each other and D, E, F are close to each other, while the shortest connection between the two groups is much longer. The MST includes that bridge. Removing the longest bridge produces clusters {A,B,C} and {D,E,F}.

Advantages: intuitive and can reveal non-spherical structure. Limitations: pairwise distance graph can be expensive for large datasets; noisy/outlier points may create long edges; deciding where to cut can require judgement.

5.2 Expectation-Maximization (EM) Algorithm

EM is an iterative method for estimating model parameters when data contains hidden/latent variables or incomplete observations. A common use is fitting a Gaussian Mixture Model for clustering.

E estimates latent assignments; M updates model parameters; repeat until convergence.
  1. Initialize: choose initial parameter estimates (for example, mixture weights, means and covariance matrices).
  2. E-step (Expectation): using current parameters, estimate the probability that each data point belongs to each hidden component (responsibilities).
  3. M-step (Maximization): update parameters to maximise expected likelihood using the estimated responsibilities.
  4. Repeat: alternate E and M steps until the log-likelihood changes very little or a maximum iteration count is reached.

Applications: Gaussian mixture clustering, missing-data estimation, image segmentation, speech processing and probabilistic modelling. Limitations: may converge to a local optimum; result can depend on initialization; convergence may be slow.

Memory cue: E = Estimate hidden membership; M = Modify parameters.

6.1 Dimensionality reduction, PCA, feature selection and LDA May 2023; May 2024; Nov 2024; May 2025; Nov 2025; Jun 2026

6.1.1 What is dimensionality reduction?

Dimensionality reduction is the process of reducing the number of input features while preserving as much useful information as possible.

Why use it? Reduces computation and storage, removes redundant/noisy variables, helps visualise data, can reduce overfitting and may improve clustering/classification when irrelevant dimensions are removed.

6.1.2 How it helps classification and clustering

  • Classification: removes irrelevant/redundant features, makes training faster, reduces noise and may improve generalization. The reduced features are then used to train a classifier such as SVM or Logistic Regression.
  • Clustering: reduces high-dimensional data to a smaller space so distance calculations become more meaningful and clusters can be visualised. PCA is often used before K-means.

6.1.3 Feature selection vs feature extraction

Feature selection Feature extraction
Selects a subset of the original features. Creates new features by transforming/combining original features.
Original meanings are retained. New features may be harder to interpret.
Methods: filter (correlation, chi-square), wrapper (forward/backward selection), embedded (L1/Lasso, tree importance). Methods: PCA, LDA and other projection/embedding methods.

6.1.4 Principal Component Analysis (PCA)

PCA is an unsupervised linear dimensionality-reduction technique. It transforms correlated original features into a smaller set of uncorrelated variables called principal components. The first component captures the maximum possible variance; each next component captures the maximum remaining variance while being orthogonal to previous components.

PCA keeps directions with high variance, then projects the data onto the selected components.

6.1.5 Steps of PCA

  1. Prepare data; handle missing values and standardize features when their scales differ.
  2. Compute the mean and centre each feature (subtract its mean).
  3. Calculate the covariance matrix.
  4. Find eigenvalues and eigenvectors of the covariance matrix.
  5. Sort eigenvectors by decreasing eigenvalue. Eigenvalue indicates the variance captured.
  6. Select the top k eigenvectors using explained variance (for example, retain around 90-95% when appropriate).
  7. The explained variance ratio of component i is λᵢ / Σⱼλⱼ. Add these ratios in order until the cumulative total reaches the chosen threshold.
  8. Project the original centred data onto these k eigenvectors to obtain reduced features.

Example: A student dataset may contain height, weight and waist size. Weight and waist size may be strongly correlated. PCA can combine the correlated measurements into a smaller number of components (for example, PC1 may represent overall body size), reducing three original features to one or two components with limited information loss.

Applications: image compression/face recognition, visualisation of high-dimensional data, noise reduction, preprocessing before clustering/classification, and financial data analysis.

6.1.6 Linear Discriminant Analysis (LDA)

LDA is a supervised dimensionality-reduction technique. Unlike PCA, it uses class labels and finds directions that best separate classes. It tries to maximise between-class separation while minimising within-class spread.

Objective (concept): maximise between-class scatter / within-class scatter
J(w) = (wᵀ Sᴮ w) / (wᵀ Sᵂ w)

Sᴮ is the between-class scatter matrix and Sᵂ is the within-class scatter matrix. For C classes, LDA can produce at most C-1 discriminant directions.

6.1.7 Steps of LDA

  1. Separate the training data using known class labels.
  2. Calculate the mean vector for each class and the overall mean.
  3. Calculate within-class scatter Sᵂ and between-class scatter Sᴮ.
  4. Find directions that maximise the ratio of between-class to within-class scatter (often eigenvectors of (Sᵂ)⁻¹Sᴮ).
  5. Select the best discriminant directions and project observations onto them.
  6. Use the reduced features for classification/visualisation.

Example: Suppose two classes of flowers have measurements of petal length and width. LDA uses the known flower labels to find a line where the two classes are as far apart as possible and each class is as compact as possible. The projected one-dimensional values can then be classified more easily.

Applications: face recognition, medical diagnosis, document/topic classification, pattern recognition and preprocessing before classification.

6.2 SVD numerical - May 2023 Q3B May 2023

Find the Singular Value Decomposition of:

A = [ [ 2, 2 ], [ -1, 1 ] ]

SVD has the form A = UΣVᵀ , where U and V are orthogonal matrices and Σ contains non-negative singular values.

6.2.1 Step 1: Find AᵀA

Aᵀ = [ [2, -1], [2, 1] ]
AᵀA = [ [5, 3], [3, 5] ]

6.2.2 Step 2: Find eigenvalues of AᵀA

|AᵀA - λI| = (5-λ)² - 9 = 0
(5-λ)² = 9 ⇒ λ = 8, 2

6.2.3 Step 3: Singular values

Singular values are square roots of eigenvalues:

σ₁ = √8 = 2√2,   σ₂ = √2

6.2.4 Step 4: Find eigenvectors and V

For λ = 8, an eigenvector is [1, 1]ᵀ. For λ = 2, an eigenvector is [1, -1]ᵀ. Normalise both by dividing by √2.

V = (1/√2) [ [1, 1], [1, -1] ]

6.2.5 Step 5: Find U using uᵢ = Avᵢ / σᵢ

v₁ = (1/√2)[1,1]ᵀ ⇒ Av₁ = [2√2, 0]ᵀ ⇒ u₁ = [1,0]ᵀ
v₂ = (1/√2)[1,-1]ᵀ ⇒ Av₂ = [0,-√2]ᵀ ⇒ u₂ = [0,-1]ᵀ
U = [ [1, 0], [0, -1] ]

6.2.6 Final answer

A = UΣVᵀ
U = [ [1, 0], [0, -1] ]
Σ = [ [2√2, 0], [0, √2] ]
Vᵀ = (1/√2) [ [1, 1], [1, -1] ]

These matrices reconstruct the given A when multiplied as UΣVᵀ.

Module 6 - 60-second recap: Dimensionality reduction

  • Dimensionality reduction cuts the number of features while keeping useful information: cheaper computation, easier visualisation, less noise and less overfitting.
  • Feature selection keeps original features (filter, wrapper, embedded); feature extraction builds new ones (PCA, LDA).
  • PCA is unsupervised: centre/standardize → covariance matrix → eigenvectors/eigenvalues → keep top-k by explained variance λᵢ/Σⱼλⱼ. It maximises variance.
  • LDA is supervised: it uses labels to maximise between-class scatter / within-class scatter and yields at most C−1 directions.
  • SVD: A = UΣVᵀ; singular values are the square roots of the eigenvalues of AᵀA. May 2023 answer: σ₁ = 2√2, σ₂ = √2.

Key terms at a glance

One-line meanings for the terms repeatedly used across the six modules. Use this to decode a question before planning the answer.

Bagging
Bootstrap aggregating: train models on random samples drawn with replacement, then vote or average.
Bias
Systematic error from assumptions that are too simple; high bias leads to underfitting.
Boosting
Build models sequentially so each one focuses on earlier errors; usually reduces bias.
CART
Classification and Regression Trees: binary-split decision trees using Gini for classification, MSE for regression.
Confusion matrix
Table of TP, FN, FP and TN that compares actual classes with predicted classes.
Core point
DBSCAN point with at least MinPts points (including itself) inside its ε-neighbourhood.
Cross-validation
Rotate validation folds (K-fold) to estimate generalization instead of relying on one split.
Entropy
Impurity measure −Σpᵢlog₂pᵢ; lower means purer. Information gain is entropy removed by a split.
Generalization error
Error on new, unseen data; estimated by the test-set error.
Gini index
Impurity measure 1 − Σpᵢ²; the split with the lowest weighted Gini is chosen.
Hyperplane
SVM decision boundary: a line in 2D, a plane in 3D, a hyperplane in higher dimensions.
Information gain
Entropy(parent) minus the weighted entropy of the children after a split.
Kernel trick
Compute similarities as if data were mapped to a higher-dimensional space, without doing the mapping explicitly.
Overfitting
Very low training error but high test error; the model has learned noise as well as signal.
Precision
TP/(TP+FP): how many predicted positives are actually positive.
Principal component
Uncorrelated direction that captures the largest remaining variance in PCA.
Recall
TP/(TP+FN): how many actual positives were found.
Regularization
Penalty on model complexity that discourages overfitting (L1, L2, pruning, early stopping).
Support vector
Training point closest to the SVM hyperplane; it determines the margin.
Underfitting
Model is too simple; high training error and high test error, usually from high bias.
Variance
Sensitivity to the particular training sample; high variance leads to overfitting.
